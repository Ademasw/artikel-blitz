# Artikel Blitz ⚡ der · die · das

Быстрый аркадный тренажёр немецких артиклей. На экране появляется слово, и нужно успеть выбрать **der**, **die** или **das**, пока не кончилось время. При ошибке игра останавливается, показывает правильный артикль, подсвечивает окончание-подсказку и через пару карточек возвращает это слово.

**▶ Играть: https://ademasw.github.io/artikel-blitz/**

Работает в браузере на компьютере и телефоне, без регистрации. Прогресс хранится на вашем устройстве.

## Режимы

| Режим | Как играть |
|---|---|
| **Выживание** | 3 жизни; на каждое слово своё время, и с каждым верным ответом его меньше |
| **Спринт** | 60 секунд: ошибка отнимает 2 с, каждые 10 верных подряд добавляют 3 с |
| **Дзен / Правила** | без таймера; можно тренировать только окончания, только смысловые группы или только исключения |
| **Разбор завалов** | слова, на которых вы ошибались и которые ещё не закрепили |
| **Ошибки раунда** | повтор ошибок сразу после игры |

## Управление

| | der | die | das |
|---|:---:|:---:|:---:|
| Клавиатура | `A` или `←` | `S` или `↓` / `↑` | `D` или `→` |
| Свайп по карточке | влево | вверх | вправо |

Клавиши работают при любой раскладке. `Esc` ставит игру на паузу.

## Словарь

Около **1260 существительных** уровней **A1–B2**, примерно поровну der / die / das. У каждого слова есть перевод и форма множественного числа, у многих есть подсказка-правило:

- окончания: *-ung, -heit, -keit → die*, *-chen, -lein → das*, *-ling, -ismus → der* и др.;
- смысловые группы: дни недели и месяцы → der, цвета и языки → das и др.;
- исключения: *der Käse*, *das Ende*, *der Sprung*, *das Abitur* и др.;
- омонимы с переводом прямо на карточке: *der / die See*, *der / das Teil*, *der / das / die Band*.

Слова, на которых вы ошибаетесь, возвращаются чаще, хорошо выученные реже.

## Для разработчиков

React 18 + TypeScript + Vite + Tailwind CSS + Framer Motion. Сервер не нужен: это статический сайт, данные хранятся в `localStorage`.

```bash
npm install
npm run dev      # локальный сервер разработки
npm test         # тесты (Vitest)
npm run lint     # ESLint
npm run build    # сборка в dist/
```

Каждый push в `main` запускает тесты и публикует сайт на GitHub Pages (`.github/workflows/deploy.yml`).

### Как добавить слова

Допишите строку в `src/data/extra/der.ts`, `die.ts` или `das.ts`:

```
Слово | мн. ч. (или -) | перевод | уровень | метка (необязательно)

Wohnung | Wohnungen | квартира    | A1 | -ung
Montag  | Montage   | понедельник | A1 | @days
Kuchen  | Kuchen    | пирог       | A1 | !chen:-chen здесь не уменьшительное: der Kuchen
```

Метки: `-окончание` означает правило окончания, `@группа` смысловую группу, `!` исключение. `npm test` проверит формат, отсутствие дубликатов и то, что артикли согласуются с правилами.

### Структура

- `src/engine/`: игровая логика без React (очередь слов, прогресс, очки, таймеры, сессия)
- `src/data/`: словарь
- `src/state/`: сохранение прогресса и настроек
- `src/screens/`, `src/components/`: интерфейс
- `docs/TZ_v1.1.md`: техническое задание

> В `.npmrc` включён `legacy-peer-deps`: без него `npm install` падает на peer-зависимостях Vitest 4.
