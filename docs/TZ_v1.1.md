# ТЗ: Artikel Blitz, аркадный тренажёр немецких артиклей (MVP v1.1)

**DER / DIE / DAS**: скоростная тренировка автоматизма, адаптивная очередь и разбор правил.

| Формат продукта | Основной стек | Хранилище | Ядро контента |
|---|---|---|---|
| SPA, только клиент | React 18+, TS (strict), Vite, Tailwind | localStorage (`artikel_blitz_v1`) | 1000+ слов (A1–B2) + правила |

> Документ основан на ТЗ v1.0 (`TZ_Artikel_Blitz_Der_Die_Das.docx`). Изменения отмечены **[v1.1]**. Сводка изменений в конце документа.

## 1. Общее описание

SPA для тренировки автоматизма в определении рода немецких существительных (der, die, das). Продукт объединяет быстрый аркадный геймплей с адаптивным повторением проблемных слов и мгновенным разбором грамматических правил.

**Ключевые принципы**
- **Нулевое трение.** Мгновенный старт, высокая отзывчивость, при правильных ответах никаких пауз.
- **Мышечная и цветовая память.** Жёсткое цветовое кодирование родов. **[v1.1]** Все способы ввода привязаны к одной раскладке позиций: der слева, die по центру/вверх, das справа. Ошибку обязательно нужно исправить.
- **Автономность.** Работает полностью на клиенте, прогресс и настройки хранятся в localStorage.
- **[v1.1] Доступность.** Цвет никогда не единственный носитель информации: артикль всегда подписан текстом.

## 3. Модель данных (TypeScript)

`src/types/game.ts`

```ts
export type Article = 'der' | 'die' | 'das';
export type Level = 'A1' | 'A2' | 'B1' | 'B2';
export type RuleType = 'suffix' | 'semantic' | 'exception' | 'none';

export interface WordItem {
  id: string;                      // [v1.1] уникален; у омонимов разные id: 'see-m', 'see-f'
  word: string;                    // Существительное с заглавной буквы, напр. "Möglichkeit"
  article: Article;
  plural: string | null;           // [v1.1] ПОЛНАЯ форма мн. ч. ("Möglichkeiten"); null, если мн. ч. нет
  translation: string;             // Перевод на русский; у омонимов обязан различать значения
  level: Level;
  ruleType: RuleType;
  highlight?: string;              // [v1.1] Конец слова для подсветки (word.endsWith(highlight)); допустим и у 'exception'
  ruleHint?: string;               // Пояснение в 1 строку
  alwaysShowTranslation?: boolean; // true для омонимов
}

export interface WordProgress {
  wordId: string;
  mastery: number;                 // 0..5, шаг 0.5
  attempts: number;
  mistakes: number;
  avgReactionMs: number | null;    // [v1.1] EMA α=0.3 по верным ответам; null, пока верных нет
  lastSeenAt: number;              // timestamp
  isProblematic: boolean;
  lastAnswerCorrect: boolean | null; // [v1.1] для правила «повторная ошибка → 0»
}

export type GameMode = 'survival' | 'sprint' | 'zen' | 'mistakes' | 'round_review';
export type LevelFilter = 'A1-A2' | 'B1-B2' | 'ALL';
export type RuleFilter = 'ALL' | 'suffix' | 'semantic' | 'exception';
export type KeyPreset = 'ASD' | 'ARROWS';

export interface GameSettings {
  soundEnabled: boolean;                 // по умолчанию true
  showTranslationBeforeAnswer: boolean;  // по умолчанию false
  keyPreset: KeyPreset;                  // по умолчанию 'ASD'
}

export interface HighScores { survival: number; sprint: number; }

export interface RoundMistake {
  word: WordItem;
  userAnswer: Article | 'timeout';
  reactionMs: number;
}

// [v1.1] Фаза игровой сессии
export type GamePhase = 'playing' | 'error_lock' | 'paused' | 'finished';

// [v1.1] Схема хранилища
export interface PersistedState {
  version: 1;
  progress: Record<string, WordProgress>;
  settings: GameSettings;
  highScores: HighScores;
  levelFilter: LevelFilter;
}
```

**[v1.1] Правила хранилища**
- Ключ `artikel_blitz_v1`, поле `version` для будущих миграций.
- Битый JSON или ошибка доступа (приватный режим, квота) не роняют приложение: используются значения по умолчанию, работа идёт в памяти.
- Прогресс по `wordId`, которого нет в текущем словаре, игнорируется (но не удаляется).
- Прогресс сохраняется после каждого ответа (debounce ≤ 300 мс), рекорды при завершении раунда.

## 4. Стартовая база слов (Seed Data)

Файл `src/data/words.ts`: **не меньше 1000** существительных без ошибок в родах и формах мн. числа (v1.2: было 200–220).

- **[v1.2]** Базовый набор (омонимы, исключения) описан в `words.ts` вручную; расширенный словарь лежит в `src/data/extra/{der,die,das}.ts` в компактном формате `Слово | мн. ч. | перевод | уровень | метка`. Метка: `-ung` (правило окончания), `@male` (смысловая группа), `!e:пояснение` (исключение).
- **[v1.2]** Автотест проверяет согласованность: слово с пометкой окончания имеет артикль этого правила; слово на «строгое» окончание (-ung, -heit, -keit, -schaft, -tion, -tät, -ling, -ismus, -chen, -lein) с другим артиклем обязано быть помечено исключением (der Sprung, der Kuchen).

- Распределение: на каждый артикль 30–36 % базы, на каждый уровень A1/A2/B1/B2 не меньше 20 %.
- **Суффиксы** (`ruleType: 'suffix'` + `highlight`):
  - der: -ling, -ismus, -or, -ant, -ist, -ich, -ig;
  - die: -ung, -heit, -keit, -schaft, -tion, -tät, -ik, -ei, -in (женский суффикс лиц), большинство на -e;
  - das: -chen, -lein, -ment, -um, -tum, -nis.
- **Смысловые группы** (`'semantic'`): дни недели, месяцы, времена года, осадки, стороны света, алкоголь, марки машин (der), цвета как существительные (das Rot), металлы, химические элементы, языки (das Deutsch) и др.
- **Исключения** (`'exception'`): слова, нарушающие правило своего окончания или своей группы. **[v1.1]** Такие слова нельзя размечать как `suffix`:
  - -e, но не die: das Ende, der Name, der Käse, der Junge;
  - -or, но das: das Labor, das Tor;
  - -ment, но der: der Moment, der Zement;
  - -tum, но der: der Irrtum, der Reichtum;
  - -nis, но die: die Erlaubnis, die Kenntnis;
  - -in, но не die (не женский суффикс): das Benzin, der Termin;
  - группы: das Bier (алкоголь обычно der), die Bronze (металлы обычно das), der Sauerstoff/Wasserstoff/Stickstoff (элементы обычно das);
  - без правила: die Butter.
- **[v1.1] Исправление:** das Mädchen подчиняется правилу -chen и исключением не является. Разметка `suffix`, highlight `chen`, хинт «Все -chen → das, даже Mädchen».
- **Омонимы** (`alwaysShowTranslation: true`): der See (озеро) / die See (море), der Teil (часть целого) / das Teil (деталь), der Leiter (руководитель) / die Leiter (лестница), der Band (том) / das Band (лента). **[v1.1]** Перевод обязан различать значения; die Band (музыкальная группа) можно добавить третьим.
- **[v1.1] Валидация словаря автотестом:** уникальные id; у каждого `highlight` выполняется `word.endsWith(highlight)`; доли артиклей и уровней в пределах нормы; каждый суффикс из списка выше встречается хотя бы раз; все пары омонимов присутствуют и помечены флагом.

## 5. Игровая механика и алгоритмы

### 5.1. Умная очередь слов (`src/engine/wordQueue.ts`)

**1. Оценка владения** (`src/engine/mastery.ts`, чистая функция `applyAnswer`):
- верно и быстрее 2000 мс: `mastery = min(5, mastery + 1)`;
- верно за ≥ 2000 мс: `mastery = min(5, mastery + 0.5)`;
- ошибка или таймаут: **[v1.1]** если `lastAnswerCorrect === false` (вторая ошибка подряд по этому слову), `mastery = 0`, иначе `max(0, mastery − 2)`; `isProblematic = true`;
- флаг `isProblematic` снимается, когда `mastery ≥ 3`;
- «на рефлексе» (статистика главного экрана): `mastery ≥ 4 && avgReactionMs < 1500`;
- **[v1.1]** `avgReactionMs`: первый верный ответ записывается как есть, далее `avg = 0.3·t + 0.7·avg`. Учитываются только верные ответы;
- **[v1.1]** нажатие правильного артикля в ERROR_LOCK попыткой не считается и mastery не меняет.

**2. Быстрый возврат (Short-term Retry)** в пределах сессии:
- после ошибки слово подаётся снова через 3–4 карточки;
- если на возврате ответ верный, контрольная проверка ещё через 10–12 карточек;
- если ошибка, цикл 3–4 повторяется;
- **[v1.1]** запланированный возврат имеет приоритет над случайным выбором, но подчиняется защите от повторов (п. 4). Если на одну позицию запланировано несколько слов, лишние сдвигаются на следующие карточки.

**3. Баланс выдачи** (survival, sprint, zen):
- **[v1.2]** корзины: новые (ещё не встречались), слабые (встречались, `mastery < 2`), средние (`2 ≤ mastery < 4`), освоенные (`mastery ≥ 4`);
- веса 30 / 30 / 25 / 15 % (в v1.1 новые и слабые были одной корзиной с весом 60 %: при словаре 1000+ слов ошибочные слова тонули среди сотен новых), при пустой корзине её вес пропорционально перераспределяется между остальными;
- **[v1.1]** внутри корзины предпочитаются давно не виденные слова: вес пропорционален `1 + min(сутки, now − lastSeenAt) / час`, у ни разу не виденных слов максимальный вес.

**4. Защита от повторов:** одно и то же слово не выпадает дважды подряд, минимальный интервал 2 другие карточки. **[v1.1]** Если в пуле 2–3 слова, интервал 1; если 1 слово, повтор разрешён.

**[v1.1] 5. Применение фильтров:** фильтр уровня с главного экрана действует в survival, sprint и zen; фильтр правил только в zen; mistakes и round_review фильтры игнорируют. Если после фильтрации пул пуст, кнопка старта неактивна с подписью «Нет слов под фильтр».

### 5.2. Обработка ответа и Error Lock-in

- События клавиатуры с `event.repeat === true` игнорируются.
- **[v1.1]** Время реакции отсчитывается с момента появления карточки (по окончании анимации входа). Таймаут фиксируется как ошибка с `reactionMs` = лимит карточки.
- **Верный ответ:** карточка улетает в сторону выбранного артикля, звучит короткий позитивный звук, следующая карточка появляется без искусственной паузы (~120–150 мс на анимацию).
- **Ошибка или таймаут (ERROR_LOCK):**
  - активный таймер (карточки в survival или общий в sprint) сразу ставится на паузу;
  - карточка трясётся (shake) и подсвечивается цветом правильного артикля;
  - на карточке раскрываются: 1) правильный артикль + слово с выделенным окончанием (Möglich**keit**); 2) мн. число (или «нет мн. ч.») и перевод; 3) бейдж правила (`ruleHint`), «Исключение!» или «Запомнить» (для `none`);
  - выйти из ERROR_LOCK можно только нажатием правильного артикля; «Далее» и пробел не работают;
  - повторное нажатие неправильного артикля трясёт кнопку, но жизни и время не списывает;
  - после правильного нажатия ERROR_LOCK снимается, таймер возобновляется, появляется следующая карточка.
- **[v1.1]** Обратная связь объявляется скринридеру через `aria-live="assertive"`. Макет при раскрытии не прыгает: зона фиксированной высоты.

### 5.3. Очки, комбо и Fever

- **[v1.1] Порядок расчёта:** при верном ответе сначала `combo += 1`, затем по новому значению берётся множитель.
- Бонус скорости: `50` при t ≤ 1000 мс; `50·(2500 − t)/1500` при 1000 < t < 2500; `0` при t ≥ 2500.
- Очки: `round((100 + bonus) × mult)`.
- Множитель: 1–4 → x1; 5–14 → x2; 15–24 → x3; 25+ → **Fever x4** (пульсирующее свечение рамки, более яркий тон звука).
- Ошибка или таймаут сбрасывают комбо в 0 и выключают Fever.
- **[v1.1]** Очки показываются во всех режимах, рекорды сохраняются только для survival и sprint, в том числе при ручном выходе.

## 6. Режимы игры и пограничные случаи

| Режим | Правила и таймеры | Завершение | Особые механики |
|---|---|---|---|
| **Выживание** (survival) | 3 жизни. Лимит карточки **[v1.1]** `max(1.7, 4.0 − 0.06·N)` с, где N = число верных ответов в сессии. Каждая карточка начинается с полным лимитом | Потеряны все жизни или выход вручную | Таймаут = ошибка: −1 жизнь, сброс комбо, ERROR_LOCK. Последняя жизнь: сначала ERROR_LOCK, потом итоги |
| **Спринт** (sprint) | Общий таймер 60.0 с, жизней нет | Таймер дошёл до 0.0 | Ошибка: −2.0 с, таймер на паузе до снятия ERROR_LOCK. **[v1.1]** Если после штрафа время ≤ 0, сначала ERROR_LOCK, затем итоги. +3.0 с при комбо 10, 20, 30… с анимацией «+3s» |
| **Дзен / Правила** (zen) | Без таймера и жизней | Кнопка «Завершить раунд» | Фильтры уровня и правила (Все / Суффиксы / Смысловые группы / Исключения) |
| **Разбор завалов** (mistakes) | Без таймера и жизней. **[v1.1]** Пул = слова с `isProblematic`, зафиксированные на старте сессии | Каждое слово пула отвечено верно в сессии или выход вручную | Ошибка отправляет слово в retry через 3–4 карточки. Если проблемных слов нет, карточка режима неактивна: «Завалов нет» |
| **Ошибки раунда** (round_review) | С экрана итогов. Пул = уникальные ошибки прошедшей сессии | Все слова отвечены верно | При ошибке слово уходит в конец мини-очереди (правило 3–4 не действует). **[v1.1]** Из итогов этого режима тоже можно прогнать ошибки |

**[v1.1]** Mastery обновляется во всех режимах.

**Таймеры.** Время считается по дельтам `performance.now()` внутри `requestAnimationFrame`, а не инкрементами `setInterval`, поэтому пауза и переключение вкладок не вызывают дрейфа и двойного списания. **[v1.1]** При `visibilitychange → hidden` в survival и sprint игра автоматически ставится на паузу.

**[v1.1] Пауза.** Esc или кнопка «Назад» в HUD ставит игру на паузу: таймеры стоят, оверлей «Продолжить / Завершить раунд». Завершение ведёт на экран итогов.

## 7. Интерфейс, управление и звуки

### 7.1. Цветовое кодирование

Тёмная тема по умолчанию, высокий контраст, фокус на карточке.

| Артикль | Род | Цвет | Применение |
|---|---|---|---|
| DER | мужской | синий `#3B82F6` / blue-500 | левая кнопка, свайп **влево**, клавиши A / ← |
| DIE | женский | розовый `#F43F5E` / rose-500 | средняя кнопка, свайп **вверх** **[v1.1]**, клавиши S / ↓ / ↑ |
| DAS | средний | изумрудный `#10B981` / emerald-500 | правая кнопка, свайп **вправо** **[v1.1]**, клавиши D / → |

**[v1.1]** Красный и зелёный плохо различают люди с дальтонизмом, поэтому на кнопках, бейджах и в обратной связи всегда присутствует текст артикля.

### 7.2. Управление (три способа ввода одновременно)

| Способ | Схема | Детали |
|---|---|---|
| Клавиатура | ASD: A → der, S → die, D → das. ARROWS: ← → der, ↓ или ↑ → die, → → das. Esc: пауза | Только `event.code` (KeyA, KeyS, KeyD, ArrowLeft…), поэтому управление не зависит от раскладки ОС. `event.repeat` игнорируется. **[v1.1]** Клавиши обоих пресетов работают всегда; пресет определяет, какие подсказки показаны на кнопках |
| Экранные кнопки | Три крупные кнопки Der / Die / Das внизу | Высота ≥ 64 px на мобильных, бейджи клавиш на десктопе |
| Свайпы | **[v1.1]** Влево → der, вверх → die, вправо → das | Карточка наклоняется и подсвечивает рамку цветом направления, порог ~80 px. **[v1.1]** `touch-action: none` на карточке |

### 7.3. Звук (`src/utils/sound.ts`)

AudioContext создаётся лениво при первом действии пользователя (с `resume()`). Если `soundEnabled = false`, звук не играет.
- Верный ответ: короткий чистый синт-нот, высота растёт с комбо (до капа на 15+).
- Ошибка или таймаут: мягкий низкий приглушённый двойной тон.
- Бонус времени / вход в Fever: короткий восходящий аккорд.
- Новый рекорд: короткая победная отбивка на экране итогов.

### 7.4. Экраны

1. **Главный (Home):** заголовок, шестерёнка настроек; статистика «на рефлексе X / всего», рекорды survival и sprint; переключатель уровня (A1–A2 / B1–B2 / Все); сетка из 4 карточек режимов (у дзена быстрый фильтр правил, у разбора завалов счётчик проблемных слов).
2. **Игра (Game):**
   - HUD: «Назад» (пауза), жизни или таймер спринта, счёт, бейдж комбо (x2, x3, FEVER x4);
   - центр: полоска времени карточки в survival (оранжевая при < 30 %, красная при < 15 %); карточка с бейджем уровня и крупным словом (перевод до ответа, если включено в настройках ИЛИ `alwaysShowTranslation`); зона обратной связи ERROR_LOCK фиксированной высоты; микро-строка с предыдущим словом после верного ответа;
   - низ: кнопки Der / Die / Das с подсказками клавиш.
3. **Итоги (Summary):** счёт + «Новый рекорд!»; метрики: пройдено слов, точность % (**[v1.1]** верные с первой попытки / все карточки), среднее время реакции в секундах (**[v1.1]** только по верным), макс. комбо; список ошибок (артикль + слово + мн. ч. + перевод + правило) или «Идеальный раунд!». Кнопки «Сыграть ещё», «Прогнать ошибки этого раунда (N)», «В меню».
4. **Настройки (Drawer):** звук; показ перевода («Только после ответа» по умолчанию / «Всегда на карточке»); раскладка (A/S/D или стрелки); «Сбросить весь прогресс» с подтверждением.
5. **[v1.1] Оверлеи:** пауза, подтверждение сброса.

**[v1.1] Адаптивность:** `min-height: 100dvh`, отступы safe-area, ширина от 320 px без горизонтального скролла; при `prefers-reduced-motion` вместо вылетов и тряски используются простые fade-переходы.

## Дополнения v1.2

- **Режим «Падежи».** Раунд из 20 предложений с пропуском перед существительным: `Was machst du mit ___ Hund?`. Шесть кнопок: der / die / das (клавиши A S D) и den / dem / des (Z X C), также 1–6. Падежи: Nominativ 10 %, Akkusativ 35 %, Dativ 35 %, Genitiv 20 %; падеж задаёт глагол или предлог шаблона. Род слова до ответа не показывается. Ошибка — ERROR_LOCK как в основной игре: правильная форма, причина (`mit + Dativ`) и строка таблицы склонения; задание возвращается через 3 карточки. В режим не попадают: слабое склонение мужского рода (den Studenten), омонимы, B2, языки, цвета, числа, дроби, марки. Genitiv для мужского и среднего рода — только многосложные слова не на s/ß/x/z (`des Computers`), чтобы форма существительного была надёжной.
- **Цель на день и серия.** `daily: Record<YYYY-MM-DD, {answers, correct}>` по локальной дате, хранится 400 дней; ответы всех режимов, включая падежи. Цель 20 / 50 / 100 / 200 (по умолчанию 50). Серия не обрывается, пока сегодняшняя цель не выполнена: считается от вчера.
- **Статистика.** Слова по уровням (не встречалось / учу / почти / выучено), правила с наибольшей долей ошибок (от 5 ответов) с запуском тренировки на словах правила, падежи, активность за 5 недель.
- **Озвучка** (Web Speech API, `de-DE`): выключена / при ошибке (по умолчанию) / всегда. Фраза — артикль со словом или предложение целиком.
- **Перенос прогресса** без сервера: JSON-файл или код `AB1.` (deflate-raw + base64url). Импорт объединяет: по слову — запись с бо́льшим `lastSeenAt`, рекорды — максимум, день — запись с бо́льшим числом ответов; настройки локальные. Повторный импорт ничего не меняет.
- **PWA:** манифест, иконки, service worker (страница — сначала сеть, сборка — из кэша, шрифты — из кэша с фоновым обновлением). Кнопка установки в настройках (Chrome/Android), инструкция для iPhone.
- **Хранилище:** версия остаётся 1, новые поля необязательны — старые сохранения читаются без потерь.
- **Дизайн:** школьная доска и бумажные карточки для слов; Fira Sans / Fira Sans Condensed.
